xcertplay · Warp 终端风格 UI 提案

画布 2560×1600。把现有的深灰 + 绿色调继续往前推一步：去掉玻璃、投影与圆角胶囊，改成 平面块 + 1px 细线 + 等宽字体；状态用文字与符号表达，而不是靠颜色堆叠。所有数值仍来自 现有实现（分辨率、帧率、HEVC、MFi 通道、日志路径），只是换了表达方式。

设计原则

  • 块化：命令与输出各自成块，块间留空，不再通栏糊成一片
  • 平面：零投影、零渐变卡片，只有 1px 线分层
  • 等宽：数字对齐，滑杆与状态都用字符/方块表达
  • 克制：颜色只用于「开 / 连接 / 错误」三种语义
