NEVOPlay · 面板式设置页 提案

今天呼出设置 = 关掉整个 controller：画面立刻断、手机掉一次 CarPlay、返回时再重连一次。 已经改成「设置盖在运行中的会话上」，但面板仍是不透明的全屏——画面在跑却看不见。 下面三屏是同一套设置内容的三种几何排布，共同前提是：会话不断、画面继续解码， 面板只遮住一部分，让你在调设置时仍看得见导航/音乐。

三种排布

  • 屏 1 右栏 940px：最像车机原生设置；左侧导航区完整保留
  • 屏 2 底部抽屉 720px：上方画面最宽，像 Android Auto 的下拉抽屉
  • 屏 3 居中浮层（半透明 + 模糊）：四周都能看见画面，但遮住画面正中

交互规则（三屏一致）

  • 面板打开时触摸只给面板，不进 CarPlay
  • 三指双击 / 返回键 / 左上 ❯ 都是「返回」：丢弃改动，画面从未中断
  • 只有「保存并重连」重建会话，并保留 Wi-Fi 组，手机几秒回到同一地址
  • 顶部常驻一行会话心跳：● 运行中 · 地址 · 编码 · 分辨率
  • 退出应用仍在面板底部，红色描边，不放主操作旁边

取舍

  • 面板越透明越贵：模糊要每帧重算，车机 GPU 不一定吃得消 → 建议默认不透明右栏，模糊版做成可选项
  • 右栏会遮住 CarPlay 右侧图标；底部抽屉遮住下方一行
  • 面板内滚动区与固定底栏分离，避免「保存」被滚出屏幕
  • 窄面板放不下一行两项，所以列数由宽度决定（≥1400 两列，否则一列）
